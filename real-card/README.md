# Measurements with physical DNIe cards

This folder will hold the measurements made with real DNIe cards and readers by the corresponding author:

| Test | Measure |
| --- | --- |
| Timed logins | total login time and card signing time over 20 complete logins |
| Wrong PIN | client and server behaviour after one wrong PIN entry |
| Card removal | behaviour when the card or the reader is removed before signing |
| Real certificate chain | acceptance of a signature that chains to the issuer's production roots |

Equipment (operating system, reader model, card version, driver and client versions) will be listed with the results. Personal data (names and DNI numbers) are removed before publication.
